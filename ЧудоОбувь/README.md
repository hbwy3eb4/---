Чудо Обувь — система оформления заказов

ехнологии
- Python 3 + Tkinter
- PostgreSQL
- psycopg2, pandas

Запуск
1. "sudo -u postgres createdb chudoobuv"
2. "python3 db.py" — создаст таблицы и зальёт данные
3. "python3 main.py" — запустит приложение

Функции
- Каталог с фильтром, поиском, сортировкой
- Логин по логину (без пароля)
- Оформление заказов
- Управление заказами (менеджер, админ)
